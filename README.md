# 🌐 IPv6 子网计算器 V0.4

**简体中文** | [English](README_EN.md)

## 📖 项目简介

IPv6SubnetCalculator 是一款适用于 Windows 的离线 IPv6 子网计算工具，可快速分析网络范围、划分子网、识别地址用途，并查询和保存计算结果。

## ✨ 主要功能

- **网络计算**：支持 IPv6 CIDR `/0`～`/128`，计算网络起始与结束地址、子网数和地址容量；自动规范地址大小写，并对输入错误给予明确提示。
- **前缀分析**：提供常用目标前缀快捷选择，显示新增子网位数；对 `/127`、`/128` 等边界情况给出清晰说明。
- **地址类型与部署提示**：识别 ULA、链路本地、组播、6to4、Teredo、文档地址等，提示典型用途和网络部署限制，并提供 RFC、IANA 参考。特殊地址仍可正常进行数学划分。
- **分页与复制**：按 25、50、100、200 项分页，可翻页、跳页、复制选中记录或当前页；数量极大时紧凑显示，悬停可查看完整统计。
- **统一定位**：使用一个下拉框选择 IPv6 地址、子网序号、IPv6 地址范围或子网序号范围。快速跳转对应页面，高亮命中的子网；跨页范围在翻页后继续高亮。
- **子网详情**：双击结果列表中的子网，查看该子网的起始地址、结束地址与地址数量，并可一键复制详细信息。
- **文件导出**：支持导出全部子网或指定序号范围为 TXT、Excel（XLSX），提供进度、取消、容量估算和大规模导出提醒。

- **范围复制**：通过独立的范围复制图标，输入起止子网序号后复制到剪贴板，单次最多 5,000 项；更多记录可使用文件导出。
- **子网详情连续浏览**：详情窗口提供“上一条”“下一条”，可直接切换相邻子网，同时保持列表定位。

## 🆕 V0.4 更新

- 支持双击查看子网详情、复制详情和上一条／下一条连续浏览。
- 定位功能整合为统一下拉框，支持单个地址、子网序号以及两种范围定位；范围跨页高亮。

## 📦 下载与使用

从 GitHub [Releases](../../releases) 获取可用的 Windows 程序，双击运行即可。

输入 IPv6 网络及目标前缀，点击计算图标。可以浏览子网列表、双击查看详情，或者从定位方式下拉框选择单项或范围定位。需要保存结果时，点击导出图标并选择全部或指定序号范围。

## 💡 使用说明

- 默认示例网络为 `2026:1015:abcd::/48`。
- IPv6 没有广播地址，界面上的“网络结束地址”代表该网段的最大地址。
- Excel 单工作表最多包含 1,048,575 条子网记录（另预留一行表头）；数量更多时可使用 TXT。超大规模导出需要足够的时间和存储空间。
- 地址类型提示不等于公网路由可达性或分配授权。相关标准参考：[IANA IPv6 特殊用途地址登记表](https://www.iana.org/assignments/iana-ipv6-special-registry)。
