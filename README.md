# 🌐 IPv6 子网计算器

**简体中文** | [English](README_EN.md)

## 📖 项目简介

IPv6SubnetCalculator 是一款适用于 Windows 的轻量级离线 IPv6 网络及子网计算工具，便于查询网络范围、划分子网和保存计算结果。

## ✨ 主要功能

- 校验 IPv6 地址与 CIDR 前缀（`/0`～`/128`），自动规范化至所属网络
- 计算网络起始地址、结束地址、子网总数与每个子网的地址数量
- 使用压缩格式显示 IPv6 地址，子网列表居中展示
- 子网分页浏览，每页可选 25、50、100、200 项，支持翻页和页码跳转
- 复制选中的子网或整个当前页面的子网地址；列表支持 `Ctrl+A` 全选当前页、`Ctrl+C` 复制
- 导出全部子网为 Excel（XLSX）或 TXT，显示进度并支持取消
- 超出 Excel 行数限制时提醒并允许确认后改为 TXT 导出
- 对无效输入提供清晰的中文错误提示

> 💡 **说明：** Excel 单工作表最多可保存 1,048,575 条子网记录（预留一行表头）。TXT 导出不受这一行数限制，但超大规模导出可能耗费较多磁盘空间与时间。IPv6 不存在广播地址，“网络结束地址”仅表示网络范围中数值最大的地址。

## 🆕 V0.3 新增功能

- **前缀划分分析**：在计算摘要中显示新增子网位数（例如 `/48 → /64`，新增 16 位），并保留可划分子网数统计。
- **常用前缀快捷选择**：提供 `/48`、`/56`、`/60`、`/64`、`/127`、`/128` 常用目标前缀，根据原始网络前缀过滤不适用选项；选择后直接计算，同时保留手工输入。

- **IPv6 地址类型识别**：计算完成后展示网络地址类型、用途说明及相应规范参考。
- **网络部署提示**：区分普通全球单播、内部网络与 VPN 可用的 ULA、链路本地、历史隧道及文档保留地址等类型；对覆盖多种地址用途的大范围前缀给出明确提醒。
- **计算不受限制**：特殊地址仍可进行数学上的子网划分；地址可计算不代表已获分配或适合公网互联。

> 💡 **地址用途说明：** 类型识别依据内置的常见 IANA 特殊用途登记项与 RFC 规范；结果不代表实时登记状态、实际地址分配权或公网可达性。参考：https://www.iana.org/assignments/iana-ipv6-special-registry

## 📦 下载与使用

在 GitHub [Releases](../../releases) 页面获取发布的 Windows 版本。下载 `IPv6SubnetCalculator.exe` 后双击即可使用，无需安装。

输入 IPv6 网络地址及原始前缀、目标子网前缀，然后点击“开始计算”。可直接翻页、复制子网，输入地址定位所属子网，或选择“导出”并指定全部或部分范围保存为文件。
