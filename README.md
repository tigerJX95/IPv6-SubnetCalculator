# 🌐 IPv6 子网计算器 V0.7

**简体中文** | [English](README_EN.md)

## 📖 项目简介

IPv6SubnetCalculator 是一款适用于 Windows 的离线 IPv6 子网计算工具，可分析网络范围、划分子网、识别地址用途，并通过双标签页浏览、定位及保存大量子网。

## ✨ 主要功能

- **网络计算**：支持 `/0`～`/128` 的 IPv6 CIDR，计算网络范围、可划分子网数量和每个子网的地址容量。自动规范地址大小写，对常见输入错误显示中文说明。
- **前缀与用途分析**：常用目标前缀快捷选择、新增子网位数、ULA、6to4、组播、链路本地等特殊地址类型与实际部署提示，并提供相关规范参考。
- **双标签页**：在“子网计算”查看参数、计算摘要与地址用途，在“子网结果”查看完整表格和操作工具。切换标签不会清除页码与定位范围。
- **分页与定位**：支持每页 25、50、100、200 条，以及首页、上一页、下一页、末页和页码跳转。可按 IPv6 地址、子网序号、地址范围或序号范围定位；范围高亮可跨页保留。
- **选中子网统计**：显示本页选中条数、首末序号、连续性及所选子网的地址总量；非连续选择仅累计实际选中的子网。悬停查看完整精确值，点击可复制统计。
- **多选与复制**：支持 Ctrl+单击多选、Shift+单击连续选择、Ctrl+A 全选本页、Ctrl+C 按序号顺序复制、Esc 清除选择。可直接复制当前页或指定序号范围（范围复制单次最多 5,000 条），也可双击查看子网详情并切换上一条、下一条。
- **文件导出**：支持导出全部子网或指定范围为 TXT、Excel（XLSX），提供容量估算、进度与取消操作。

## 🆕 V0.7 更新

- 修复极大序号范围导出 Excel 时的精度风险：当范围含超过 15 位的序号时，序号列统一以文本保存，并自动调整列宽。
- 修改每页条数后，保留原页首子网所在位置，继续保留定位范围高亮，不再无条件返回首页。
- 统一复制失败提示，剪贴板暂时不可用时保留选择；范围复制窗口保持打开，可直接重试。
- 统一计算页与结果页的成功、错误和一般提示颜色，补充定位失败和清除操作反馈。
- “定位”和“清除高亮”改为图标按钮，提供鼠标悬停提示及正常、悬停、禁用状态；图标按钮支持聚焦后按 Enter 执行。

## 📦 下载与使用

从 GitHub [Releases](../../releases) 获取 Windows 程序。输入 IPv6 网络地址与目标前缀并点击计算；计算完成后可在“子网结果”标签页浏览和操作完整列表。

## 💡 使用说明

- 默认示例网络为 `2026:1015:abcd::/48`。
- IPv6 没有广播地址，界面的“结束地址”指网段最大地址。
- 手动选择仅作用于**当前页**，翻页或修改每页条数后清除；切换标签保留选择。定位时仅选中首条，高亮范围会跨页保留，范围总数与本页高亮数分别显示。
- 修改每页条数时，以原页首子网为定位点切换到新页；调整后的页码会随每页条数变化。
- 选中子网的地址总量是数学容量，不代表实际可分配主机数量。巨量数值会使用紧凑格式显示，悬停查看完整值；复制统计始终保留精确整数。
- 跨页复制请使用指定序号范围，超过 5,000 条请使用文件导出。
- Excel 单工作表最多导出 1,048,575 条子网记录，超出时可使用 TXT。
- Excel 导出范围含超过 15 位的序号时，整列序号以文本保存，确保数字完整；普通序号仍以数值保存。
- 地址类型识别不代表已获得地址分配授权或公共互联网可达性。参考：[IANA IPv6 特殊用途地址登记表](https://www.iana.org/assignments/iana-ipv6-special-registry)。
